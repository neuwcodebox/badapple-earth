# P6 — Astra 서브에이전트의 300프레임 후보 선택

## 범위와 선택 방식

관련 요구·단계는 F6·F7·F9·F11, N1–N7, P6이다. 구독 사용량을 활용해 Astra가 현재 후보 중 최종 사진을 고르는 10초 비교를 실행했다. 기존 `p6-grid32-full`의 32×24 MSE Top-20을 사용했으며 대상은 38–48초의 모든 원본 300프레임(source slot 1139–1438)이다. 30000/1001fps로 인코딩한 길이는 10.01초이며 비교는 무음이다. 전곡 설정은 MS-SSIM을 유지한다.

사용자의 요청에 따라 대상 전체를 seed `20261103`으로 섞은 뒤 세 에이전트에 100프레임씩 배정했다. 각 에이전트 안에서도 무작위 순서로 제시했으며 각 프레임의 후보 순서는 source slot을 포함한 별도 seed로 섞었다. 연속 구간을 에이전트별로 나누지 않았다. 공개 job은 가림 case ID·시트 경로·결과 경로만 담고 실제 프레임·시간·기존 순위·점수·선택과의 매핑은 비공개 파일에 보관했다.

각 시트는 256×191 원본과 같은 크기의 실제 원색 후보 20장이다. `gpt-6-astra` 세 에이전트를 `low` reasoning으로 실행해 20시트씩 읽고 선택 ID만 JSONL에 저장하도록 지시했다. 원본과 사진의 명암 극성·윤곽·배치를 비교하고 다른 프레임의 해석을 가져오지 않도록 했다. 추가 조사·점수 계산·설명·재평가·하위 에이전트 생성은 맡기지 않았다. 에이전트당 최초 작업 한 번으로 100개를 저장했으며 추가 지시는 없었다. 같은 문맥 안의 판단들이 완전히 독립적이라는 보장은 없다. 이번 실행은 앞선 고정 12시점의 high reasoning 검토와 다른 선택 조건이다.

## 실행과 산출물

`production/visual.py`의 `prepare`와 `render`로 시트 준비·가림 매핑·선택 수집·비교 인코딩을 구현했다. 재실행 시 완료된 준비와 선택을 보존한다. 준비에는 기존 PNG 627개와 로컬 RGB에서 얻은 451개를 사용했으며 원격 읽기는 0회다. 검색과 MS-SSIM을 재계산하지 않았고 유료 API를 호출하지 않았다.

- 준비: 18.267초.
- 세 에이전트 선택의 관측 경과: 약 252초. 세 작업을 전달한 뒤부터 모든 완료 응답을 받을 때까지이며 주 에이전트의 조율 시간도 포함한다. 정확한 모델 추론 시간이나 구독 사용량은 계측되지 않았다.
- 비교 영상 렌더: 3.137초.
- 선택 300개 중 기존 MS-SSIM과 다른 view는 249개, MSE와 다른 view는 275개다. 변경 수는 품질 개선의 근거가 아니다.

동일한 처리율을 전곡 6,955프레임에 단순 비례하면 약 97분이다. 전곡 실측이나 완료 보장이 아니며 장시간 실행의 구독 한도는 이번 결과로 추정하지 않는다.

산출물은 `data/reviews/astra-selection-300/`에 둔다.

- `comparison.mp4`: 왼쪽부터 원본·MSE·MS-SSIM·Astra. 네 패널은 같은 canonical 크기이며 실제 MSE 순위·시간·프레임 카운터만 표시한다.
- `preview.png`: 동일 레이아웃의 대표 화면.
- `selected.parquet`: source PTS 순서의 Astra 선택과 실제 view·장소·좌표·촬영일·회전·검색 순위·MS-SSIM 선택 ID.
- `sheets/`, `jobs/`, `choices/`: 실제 시트·무작위 배정·모델 선택 원본. `private-map.json`에 가림 ID와 실제 출처를 연결한다.
- `manifest.json`: 입력·인덱스·무작위 seed·모델·reasoning·시간·실행 범위. 실험 ID는 `dbe334ba06ecac6507c647d186e0e25ddedbd67665c47e11ccc6236d3a516785`다.

## 확인 범위와 다음 판단

새로운 경계인 무작위 프레임 배정의 누락·중복 방지와 선택 파일의 소속·제시 후보·미완료 계약에 한해 빠른 테스트 두 개를 실행해 통과했다. 실제 선택 파일의 필수 항목과 전체 대상 충족은 렌더 입력으로 읽는 과정에서 처리했고 인코더는 정상 완료했다. 기존 검색·MSE 1위·다운로드·전체 테스트를 다시 검사하지 않았다.

이번 산출물의 시각적 우열과 재생 중 선택의 흔들림은 사용자의 영상 비교로 판단한다. 모델이 후보를 실제로 골랐다는 사실과 MS-SSIM보다 영상이 좋아졌다는 주장은 구분한다. 전곡 Astra 선택은 아직 실행하지 않았다.
