# P6 — 후보 재평가와 간결한 화면

관련 요구: F6–F11, F14, N1–N7. 후보 목록이 항상 첫 항목으로 연결되는 문제를 해결하도록 검색 순위와 최종 평가를 나누고, 영상 화면에서는 타이틀·슬로건을 없애며 카운터·점수를 작고 정돈되게 유지한다.

## 방법과 근거

MSE 전수 검색과 Top-20은 보존한다. 여기서 MSE 순서대로 고른 서로 다른 다섯 장소를 5단계 MS-SSIM으로 비교한다. 알고리즘은 여러 해상도에서 contrast/structure를, 가장 작은 해상도에서 luminance까지 비교한다. 이 작품에서 더 좋은 재생 결과를 보장하는 지표라고 가정하지 않고, 이전 MSE 전곡을 보존해 비교한다.

출처는 [MS-SSIM 원 논문](https://ece.uwaterloo.ca/~z70wang/publications/msssim.html)과 [SSIM 저자 자료](https://www.cns.nyu.edu/~lcv/ssim/)다. 이 문헌의 일반적인 이미지 품질 평가와 실루엣/자연사진의 매칭을 구분한다. 가우시안 11×11·σ1.5, K1=.01·K2=.03, 5개 가중치 .0448/.2856/.3001/.2363/.1333, 2×2 downsample·홀수 reflect padding을 버전으로 고정한다. 단계 평균의 음수 분수 거듭제곱을 막기 위해 [1e-8,1]로 제한한다.

실제 source frame마다 다섯 후보를 평가한다. coarse 특징이 같더라도 full grayscale이 다를 수 있어 MSE query 묶음을 그대로 재평가 단위로 쓰지 않는다. 동률은 기존 MSE 순위·view ID로 정한다. 후보 순서를 바꾸거나 강조선을 움직이려고 선택을 강제로 바꾸지 않는다. 8개 프로세스·유한 candidate 통계 캐시·180프레임 체크포인트를 사용한다.

## 화면과 재사용

타이틀·슬로건·SOURCE/MATCHED PLACE 등의 중복 라벨·수집량 표시는 없앤다. 원본 아래에는 시간·프레임 카운터와 가는 진행선을 모으고, 각 후보 아래에는 번호와 MS-SSIM 점수를 같은 위치에 정렬한다. 큰 사진 아래에는 실제 좌표·촬영일만 한 줄로 남긴다. 출처 고지는 작은 글씨로 유지한다. 선택 위치에 따라 후보 테두리와 연결선을 바꾸며 원래 사진의 색상·광도를 유지한다.

완료한 `p6-full`의 타깃·검색·썸네일·native PNG를 hard link로 재사용한다. 새 테이블과 manifest는 원자적으로 교체해 기준 결과를 보존한다. 새 선택에 필요한 큰 사진만 추가 읽고 수신 확인용 재다운로드는 하지 않는다. 출력은 `data/runs/p6-refined/`다.

## 실행·확인

MS-SSIM의 동일 이미지 최대·구조 불일치·동률 및 1번 이외 후보 선택, 실제 선택 위치 강조, 시간 카운터 분 경계와 기존 전체 프레임/segment 계약 테스트 4개가 통과했다.

실제 6,955프레임 재평가는 38.19초에 완료했다. 선택 위치 1/2/3/4/5의 수는 2,351/1,460/1,177/930/1,037프레임이다. MSE의 첫 후보와 다른 선택은 4,604프레임이며 이를 품질 개선 프레임 수로 해석하지 않는다.

## 실제 산출물과 한계

`data/runs/p6-refined/`에 `final-16x9.mp4`(1920×1080, 204,276,791bytes)와 `satellite-full.mp4`(1444×1080, 205,984,300bytes)를 완성했다. 두 파일 모두 6,955프레임·30000/1001fps·start 0·232.065167초 영상과 원본 9,997프레임·232.129887초 오디오를 유지함을 FFprobe로 한 번씩 확인했다. 원본의 약 65ms 오디오 꼬리도 보존했다.

선택은 1,333개 실제 장소·1,562개 view다. 현재 선택의 native 디테일 698개 중 299개는 이전 PNG를 재사용했고 새로 필요한 399개 view를 읽었다. 추가 읽기 실패·대체는 0개다. 검색과 후보 썸네일을 다시 생성하지 않았다.

모든 프레임의 평균 MS-SSIM은 MSE 첫 후보 0.46915735에서 재평가 선택 0.52686600으로 올랐다. 같은 선택의 평균 MSE는 0.05315976에서 0.05708481로 증가했다. 서로 다른 지표의 수치를 혼합하거나 새 지표가 높다는 이유만으로 작품 품질이 좋아졌다고 결론 내리지 않는다. 사용자 재생 비교 전의 재평가 실험 결과다.

`mse-vs-ms-ssim.mp4`는 원본·MSE 선택·MS-SSIM 선택 순서의 3패널 비교다. 같은 source frame 1139–1438, 총 300프레임을 사용해 약 10.01초이며 추가 타이틀은 넣지 않았다. `selection-preview.png`는 source frame 1002에서 실제 다섯 번째 후보로 연결된 장면이다. 대표 화면에서 제목 없이 정돈된 카운터·점수·사진 메타데이터와 선택 강조를 확인했다. 전곡 재생의 인식성 평가는 아직이다.

원래 MSE 전곡은 `data/runs/p6-full/`에 그대로 남는다. 현행 설정의 `selection_method=mse`로 같은 간결한 화면의 MSE 선택 결과도 만들 수 있다. 설정을 바꿀 때는 다른 출력 경로를 사용한다.
