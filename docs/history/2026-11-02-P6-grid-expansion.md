# P6 — MSE 격자·후보 폭 확대

## 요청과 범위

사용자는 독립 ZNCC·Gradient Correlation 비교에서도 MS-SSIM이 가장 낫다고 평가한 뒤, 검색 격자 해상도를 높이고 후보도 넓히도록 요청했다. 최종 MS-SSIM의 계산식과 256×191 해상도를 고정하고 MSE 검색 16×12·32×24와 Top-20·Top-512를 비교한다. 두 Top-512의 합집합도 평가해 기존 coarse 후보를 잃지 않게 한다. 관련 요구는 F6·F9·F12·N1–N3·N6다.

실행 구간은 기존과 같은 38–48초의 모든 원본 300프레임이다. 기존 100만 장소·400만 회전 view의 coarse/fine 특징과 canonical RGB를 사용한다. 32 격자는 이미 저장된 3.072GB uint8 배열을 재사용하며 새 수집·다운로드·원격 재추출은 없다. 64×48 검색이나 새 경로의 전곡 실행은 이번 범위가 아니다.

## 설계와 검증

`production/grid/`에 정확 MSE 검색·MS-SSIM 전용 재평가·비교 실행을 두고 `compare-grid`와 `config/grid.json`을 추가했다. 32×24의 768차원 내적은 float32의 정수 표현 상한을 넘으므로 float64 BLAS로 정확히 계산한다. 전체 float64 캐시를 만들지 않고 현재 후보 배치만 변환한다. 기존 정수 SSE·전역 view ID 동률 순위를 보존한다.

16/20·16/512·32/20·32/512·두 Top-512 합집합의 다섯 조건을 같은 MS-SSIM으로 고른다. 합집합은 중복 view만 제거하고 장소 중복은 평가 후 다섯 표시 장소를 고를 때 정리한다. 동률은 단독 격자에서는 그 격자의 MSE 순위, 합집합은 32 격자 순위·16 격자 순위·view ID다. 실제 16 격자 Top-20 검색 순서와 MS-SSIM 선택이 기존 결과를 재현해야 한다.

이전 독립 검색 평가의 MS-SSIM 점수·출처를 재사용한다. 타깃 ID·인덱스 ID·명시적 MS-SSIM 버전을 맞추고 같은 원본 slot과 같은 dense view 주소의 점수만 합친다. 기존 `p6-correlation`은 실제 사용한 변경 없는 MS-SSIM 버전을 manifest에 명시했으며, 새 독립 검색 run에도 이 필드를 기록하도록 했다. source RGB와 평가 점수 자체를 변경하지 않는다. 새 평가기는 ZNCC·GC·FSIM을 다시 계산하지 않는다.

최소 오프라인 테스트 2개가 1.96초에 통과했다. 768차원에서 흰색에 가까운 사진의 한 픽셀 오차 1을 구분하고 배치 경계·전역 동률을 포함해 int64 직접 계산 순위와 일치하는지 확인했다. 작은/큰 후보 범위와 두 격자의 최종 MS-SSIM 선택을 분리하는 계약도 확인했다. 전체 테스트나 수신 확인용 재다운로드는 하지 않았다.

## 실제 실행과 산출물

결과는 `data/runs/p6-grid32-wide/`에 완료했다. 실험 ID는 `a169743e43bb1c1f0994f35af0911165e435b31e679b06a8da4dc59ed0eb596e`, 검색 ID는 `17e54a095bc964914547c467b5ba8fcbdf0e6e5bbf91e6483ea118107afcf530`다. 타깃 ID `6ed26d6e41b9fb13c45f6c2222ed659d93e574a4d95b856fd3b8d0e9946d969f`, 인덱스 ID `0af3913546907b7000fc31ce96d5a659e23f9492856ba7eeae11ea9715e12a6f`는 이전 비교와 같다.

16·32 격자의 Top-512 검색은 약 85.487초였고 실제 source frame 300개의 검색 계산을 수행했다. 이 값은 점수 재평가·RGB 준비·메타데이터·렌더링을 제외한다. 이후 실행은 290.487초, 그중 새 점수 계산·점수 취합 190.081초다. 검색을 별도 선행 실행하고 재개했으므로 후자의 실행 시간에 검색 시간을 포함한 것처럼 보고하지 않는다. 두 단계의 계측 합은 약 376초이며 구현 시간과 단계 사이 대기는 포함하지 않는다.

합집합은 프레임별 545–693개(평균 577.69개), 전체 22,204개 view·16,506개 장소다. 평가 대상 173,307쌍 중 38,030쌍의 MS-SSIM과 출처 6,909개를 재사용하고 135,277쌍을 새로 계산했다. 최종 표시 사진 157개는 기존 PNG 99개와 RGB shard 58개로 준비했다. 원격 읽기는 0회다.

Top-512끼리는 격자를 바꿨을 때 16프레임의 선택이 달랐고, MS-SSIM은 32 격자에서 9프레임 높고 7프레임 낮았으며 284프레임은 같았다. 높은 격자의 후보가 낮은 격자의 후보를 항상 포함하지 않으므로 두 격자를 합친다. 이 구간의 평균 점수에서는 격자 증가보다 후보 폭 증가의 영향이 컸다. 점수 차이가 영상 품질의 우열이라는 뜻은 아니다.

이 합집합은 MSE 두 격자의 후보이며 이전 ZNCC·GC 검색의 후보 전체를 포함하는 집합이 아니다. 서로 다른 검색 풀의 평균 후보 수나 MS-SSIM 점수를 확대의 동일 조건 결과처럼 비교하지 않는다.

`comparison.mp4`는 7,997,463바이트, 1920×1080 H.264·300프레임·30000/1001fps·10.010초·무음이다. 위쪽 원본·16/20·16/512, 아래쪽 32/20·32/512·합집합이다. 사진은 같은 canonical 원색 RGB이며 점수는 모두 MS-SSIM이다. `candidates.parquet`는 22,204행, `shortlists.parquet`와 `evaluations.parquet`는 각 173,307행, `selected.parquet`와 `display-five.parquet`는 각 1,500행이다. 원본 PTS·실제 출처·좌표·추출 창·회전은 dense 주소로 연결한다.

실제 300프레임의 16 격자 Top-20 검색 순서와 MS-SSIM 선택이 모두 기존 결과와 같았다. 같은 격자에서 후보를 넓히거나 두 격자를 합치면 기존 최고 점수를 잃지 않는 조건도 모든 프레임에서 충족했다. 영상 메타데이터는 ffprobe로 한 번 확인하고 대표 화면을 열어 배치·카운터·사진·순위를 확인했다. 전체 주관적 재생 평가, 새 경로의 전곡 실행과 기본값 채택은 미실시다.
