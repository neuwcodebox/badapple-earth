# P5 — 형태 우선 검색 전체 경로

- 관련 요구: F5–F11, F13, N1–N7.
- 상태: 전체 구현·10만 장소 분석 캐시·60개 목표 검색/정밀 비교·10초 무음 출력·기존 MSE 방법 비교 완료. Top-5 정지 시트를 확인했고 실제 영상 재생 평가는 미실시다.
- 근거: 사용자 제공 [v2 원문](Bad_Apple_Shape_Matching_SPEC_v2.original.md), 현재 유효한 계산·운영 계약은 [SHAPE_MATCHING](../SHAPE_MATCHING.md).

## 구현과 판단

수집기·원본 MP4·기존 인덱스와 결과는 보존했다. `shape/`에 공유 RGB 분석 캐시·PHOG/Rank·전체 view exact 검색·coarse 영역/SDF·fine 영역/SDF/양방향 joint Chamfer·시인성/형태/실제 광도 선택·출처 보고서를 구현했다. 기존 MSE Top-K를 새 경로의 앞단 필터로 사용하지 않는다. v2의 구성 요소를 후속 기능으로 미루지 않았다.

회색/단색 분류·가는 형상·경계 추출·다중 레벨 대비/광도 집계·Top-K 경계 동률·단색 후보 기준을 v2.1 운영값으로 정했다. 실제 원색 사진은 변경하지 않는다. 전체 후보의 RGB를 무손실 shard로 공유해 네 회전 grayscale을 픽셀 동일하게 재생성하고, view별 grayscale checksum을 기록한다. 이는 회전별 grayscale 4장을 별도 저장하는 것보다 작고 선택 원색 사진도 다시 받지 않는다.

시작 시 캐시 집계에서 100,000개 중 PNG 6,630개·블록 36,691개·추가 원본 읽기 필요 56,679개였다. 원본은 기존 tile을 씬·작업 블록별로 묶어 읽는다. 새 분석에 필요한 원본 읽기이며 다운로드 성공 확인용 재수신은 아니다.

초기 특징 생성의 8개 스레드 실행은 약 8.7분 시점에 CPU 누적 약 610.5초로 관측됐다. 사용자의 속도 요청을 반영해 27,098개 장소의 완료 shard 공개 후 다중 프로세스로 재개했다. 완료 데이터는 보존했다. 특징 생성·coarse/fine 비교는 Windows spawn의 8개 작업 프로세스, 원격 읽기·파일 공개는 단일 writer다. BLAS 내부 스레드는 1로 제한한다. 새로운 프로세스 방식으로 결과와 재개를 오프라인 통합 테스트에서 확인했다. GPU 하드웨어는 RTX 3060 12GB지만 현재 수식 전체를 NumPy/SciPy CPU 경로로 실행하며 GPU 사용으로 표시하지 않는다.

## 필요한 검증

작은 결정적 오프라인 계약 테스트는 최종 7개다. 평균 순위/AUC·PHOG flat, joint Chamfer의 전수 쌍 비교 일치·빈 경계, 구멍/위치/극성·형태 우선 선택, 분할 exact Top-K의 경계 동률, 전체 캐시→검색→원색 MP4·보고서·재개, 정확 EDT와 네 방향 픽셀·byte 예산을 확인했다. 실제 변경의 영향 범위에서 확인했으며 느린 전체 suite는 반복하지 않았다. 합성 데이터는 이 테스트에서만 사용하고 실제 성과로 보고하지 않는다.

## 실제 실행

입력은 기존 `data/index/p4-100k/`와 `data/targets/38s-10s-6fps/`다. 목표 시점·원본 프레임은 재추출하지 않았다. 명령은 [현재 계약](../SHAPE_MATCHING.md#명령과-산출물)에 둔다. 분석 캐시는 `data/shape-v2/p4-100k/`, 새 결과는 `data/runs/p5-shape-v2/`, 비교 기준은 `data/runs/p4-100k/`다.

분석 캐시는 1,047개 shard·100,000개 장소·400,000개 view로 완료했다. index ID는 `b9c08448f9a9207d851298c5b63989fe4729cc4a9c947cee6a3747b0390921ca`다. 실제 파일 합계는 약 18.182GB이며 첫 writer lock 생성부터 완료 manifest까지 약 40.9분이다. 마지막 재개 실행은 약 26.9분이며 원본 47,789개 장소를 345개 블록 읽기로 처리했다. 전체 네트워크 요청·수신 바이트는 미계측이다. 부모 RSS 관측 최대 약 658MiB, 부모·8개 작업 프로세스 RSS 합계의 한 관측은 약 1.6GiB였다. RSS 합계는 공유 페이지의 중복을 포함하며 전체 실행 최고값으로 주장하지 않는다.

전체 PHOG·Rank 검색은 약 201.9초였고 목표별 합집합은 3,860–4,827개다. 같은 점수 단위의 MSE 개선율을 계산하지 않는다. 최종 선택 후에는 기존 MSE 출력 사진을 새 정밀 형태 점수로 별도 평가해 진단을 남기며 새 선택에 기존 MSE 후보를 주입하지 않는다.

## 실제 전체 결과

60개 목표 모두 선택·원색 사진 출력에 성공했다. 선택은 38개 실제 장소·43개 view이며 0/90/180/270도 슬롯 수는 18/12/17/13이다. 최소 대비는 약 0.04386으로 운영 하한 0.03을 넘었고 `low_visibility=0`, `near_uniform=0`이다. 이 표시는 실제 인물 인식성의 보증이 아니다. 선택 슬롯의 원래 품질 정책은 이전 AND 14개·데이터셋 마스크 46개이며 출처 행을 다시 연결해 정확히 기록했다.

| 같은 v2.1 정밀 점수로 본 출력 | 기존 10만 MSE 선택 | 새 형태 우선 선택 |
| --- | ---: | ---: |
| 평균 D_shape (낮을수록 좋음) | 0.31574546 | 0.25093265 |

58개 목표에서 형태 거리가 낮아졌고 1개 동률·1개 높아짐이다. 높은 한 프레임은 slot 10, 기존 0.31396·새 0.31884였다. 후보 절단과 형태 동급에서 실제 광도를 우선하는 최종 선택 때문에 모든 프레임의 순수 형태 거리 개선을 보장하지 않는다. 이는 같은 형태 척도의 비교이며 MSE 수치와의 직접 비교나 지각적 성공 판정이 아니다.

속도 요청으로 21개 완료 지점에서 중지해 [정확 커널·접근 최적화](2026-11-01-P5-shape-optimization.md)를 적용하고 완료 점수를 재사용했다. 다음 두 프레임은 19.44/13.88초, 마지막 37개는 총 320.66초·중앙값 5.344초(범위 4.391–27.094초)였다. 프레임의 복잡도와 회색 레벨 분기가 달라 이 수치로 전체의 보장 가속 배수를 계산하지 않는다. 처음 21개와 이후의 EDT/Chamfer backend를 타깃별로 남겼다. GPU는 사용하지 않았다.
