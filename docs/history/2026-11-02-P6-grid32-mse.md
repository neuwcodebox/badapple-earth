# P6 — 32×24 MSE 직접 선택 전곡

## 요청과 실행 조건

사용자는 32×24 Top-20/MS-SSIM 전곡을 본 뒤 MSE 방식도 실행하도록 요청했다. 격자·데이터·입력·표시 크기를 그대로 두고 최종 선택만 MSE 검색 1위로 바꾼다. MS-SSIM 기본 프리셋과 이전 결과를 덮어쓰지 않고 `config/production-mse.json`과 별도 run을 사용한다. 관련 요구는 F1·F6–F9·F11·F14·N1–N3·N5·N6다.

`reuse_run=data/runs/p6-grid32-full`에서 같은 32×24 Top-20 검색·타깃·사진을 재사용한다. `selection_method=mse`의 기존 구현을 실행하므로 새 거리 알고리즘·전수 검색·MS-SSIM 계산이 없다. 모든 프레임의 원래 MSE 1위를 선택하고 화면의 점수도 MSE를 표시한다. MSE는 낮을수록 좋으며 사진 원색이나 밝기를 변경하지 않는다. 실제 선택과 MSE 상위의 다른 네 장소를 보여준다.

출력은 `data/runs/p6-grid32-mse/`의 설명 화면 전곡·사진 전용 전곡과 같은 38–48초의 원본/MSE/MS-SSIM 비교다. 전곡은 6,955개 source frame·원래 fps·전체 원본 AAC를 유지하며 비교 클립은 같은 300프레임의 무음이다. 새로 선택되어 큰 화면에 처음 필요한 native 픽셀만 추가 읽는다. 수신 확인을 위한 재다운로드는 하지 않는다.

이번 변경은 실행 프리셋·문서다. 변경한 알고리즘이 없으므로 새 단위 테스트나 전체 테스트를 추가하지 않았다. 정상 완료한 선택 로직의 결과를 다시 대조한 것은 불필요했다는 사용자 피드백을 받았으며, 같은 중복 확인은 반복하지 않는다.
