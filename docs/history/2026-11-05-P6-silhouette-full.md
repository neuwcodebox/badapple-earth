# 윤곽·색감 연속 알고리즘의 콘텐츠 전곡 제작

관련 요구·단계는 F1, F5–F9, F11–F14, N1–N7, P5–P6다. 사용자는 색감 비교 뒤 최신 알고리즘으로 전체 영상 제작을 요청했고, 도중에 중단 후 재개할 수 있도록 진행하라고 지시했다. 현재는 계속 실행하며 명시적 중단 요청 시 저장 후 멈춘다. 콘텐츠 끝은 앞서 확정한 3분 38.5초다. 취소된 수집 규모 비교나 기존 계약의 반복 검수는 하지 않는다.

## 실행 조건

- 입력은 보존한 로컬 MP4와 완료한 `data/runs/p6-aerial120-views30-full/`의 타깃·현재 선택이다. 218.5초 이전 PTS의 **6,549프레임**을 사용한다. 출력 프레임 길이 합계는 CFR 기준 약 218.5183초이며 프레임 시작점으로 구간을 고른 결과다.
- 전체 **120만 장소·2,880만 view**, 30° 간격 회전·75% 크롭, 기존의 영역 .35·signed gradient .35·실제 경계 대비 .30과 시인성 조건을 유지한다. 색 경로는 형태 최고점 .02 이내·최대 24개·색 가중치 .2다. 색 선택은 전체 콘텐츠에 하나의 경로로 적용한다.
- fine 특징이 동일한 질의는 **6,415개**다. 완료한 38–48초와 135–145초·205–215초의 **900개 질의**를 재사용하고 **5,515개**를 검색한다. `config/silhouette-full.json`이 설정이며 `production/silhouette/full.py`가 검색부터 두 최종 영상까지 이어간다.
- 후보 메타데이터·점수를 배치로 저장하고 정밀 평가 뒤 최대 24개와 표시할 다섯 장소만 스트리밍 보관한다. 고해상도 타깃 특징은 mmap 공유하며 RGB는 source 파일별로 모아 읽는다. 선택 사진은 기존 native 자산을 재사용하고 없는 상세 사진만 기존 방식으로 준비한다.
- 산출물 경로는 `data/runs/p6-silhouette-color-full/`다. `final-16x9.mp4`와 `satellite-full.mp4`에 해당 구간의 원본 AAC를 복사한다. 기존 완성 영상·원본·비교 자료는 보존한다.

## 중단·재개 계약과 실행 근거

```powershell
$env:OPENBLAS_NUM_THREADS = '8'
$env:OMP_NUM_THREADS = '8'
$env:NUMBA_NUM_THREADS = '8'
uv run python -m badapple_earth.production.silhouette.full --resume
# 다른 터미널에서 완료 배치 저장 후 중단 요청
uv run python -m badapple_earth.production.silhouette.full --pause
```

루트 `pause.request`가 생기면 검색은 다음 체크포인트를 확정한 뒤 멈춘다. CPU 단계는 새 작업 배정을 멈추고 실행 중인 배치의 결과를 저장한다. root manifest가 `paused`가 된 뒤 프로세스가 종료된다. `--resume`은 요청 파일을 해제하고 체크포인트·배치·선택·사진·180프레임 영상 구간을 재사용한다. 강제 종료는 마지막 확정 지점 이후의 미완성 배치/구간만 재처리한다. 검색 진행은 `retrieval/progress.json`, 이후 정밀 평가 진행은 루트 `progress.json`이다.

새 중단·재개/메모리 계약 테스트 **5개 통과**: 완료 배치 보존과 남은 작업만 재개, mmap용 타깃 특징 직렬화 전후 metric 일치, 검색 중단의 다음 offset과 재개/무중단 결과 일치, 스트리밍 후보 축소의 최종 형태 허용폭과 fallback 보존, 완료 질의는 재검색하지 않고 남은 질의만 처리하며 기존 검색 결과를 그대로 재사용하는 계약이다. 합성 입력은 테스트 전용이다. 기존 출처·좌표·변환을 다시 검수하지 않았다.

실제 전곡 검색은 21:34경부터 진행했다. 초기 구현을 전체 파이프라인으로 연결하며 체크포인트를 이어갔다. **5,313,632 view·누적 670.361초**에서 실제 `--pause` 후 `paused`와 정상 프로세스 종료를 확인했고, `--resume`으로 해당 지점부터 다시 진행했다. 실제 강제 종료 시나리오나 전체 후속 단계 완료를 이 관측으로 주장하지 않는다. 재개 로그는 `.local/silhouette-full-resumed.log`다.

21:46에는 검색 5,706,848/28,800,000 view, 검색 잔여 추정 약 49분이었다. 최초 전체 예상 4–6시간은 실측 검색 속도에 따라 **11월 5일 23:30–6일 00:30 KST**로 갱신했다. 정밀 평가·상세 사진 준비는 아직 실행 전이므로 전체 예상은 변할 수 있다. **최종 영상과 전체 사용자 재생 평가는 아직 완료가 아니다.**

## 검색 완료 후 사용자 지정 일시중단

사용자가 검색만 끝내고 일시중지하도록 요청했다. `--stop-after-search` 옵션을 추가해 검색 완료 직후 후보 구성보다 먼저 `pause.request`와 `completed_stage: retrieval`을 저장하고 `paused`로 종료하게 했다. 기존 검색 체크포인트를 이어서 **2026-11-05 22:34:33 KST**에 **28,800,000/28,800,000 view** 검색을 완료했고 프로세스는 종료 코드 0으로 멈췄다. 누적 검색 시간은 **3,581.890초**다. root manifest는 `paused`, 검색 잔여 시간은 0이다. 후속 후보 구성·메타데이터·정밀 평가·색감 선택·영상 생성은 시작하지 않았다.

저장 경로는 `data/runs/p6-silhouette-color-full/retrieval/retrieval.npz`와 `progress.json`, 루트 `manifest.json`이다. 로그는 `.local/silhouette-full-search-only.log`다. 재개 지시가 오면 `--stop-after-search` 없이 `--resume`을 실행한다. 완료한 검색은 다시 계산하지 않고 이후 단계부터 이어가며, 위의 완료 시각 예상은 일시중단으로 더 이상 유효하지 않다. 새 예상은 재개 후 안내한다.
