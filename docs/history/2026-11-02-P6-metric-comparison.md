# P6 — Top-20의 다섯 지표 비교

## 요청과 범위

사용자는 기존 MSE와 MS-SSIM의 우열이 애매하다고 평가하고 다른 비교 알고리즘 시험을 승인했다. FSIM·다중 해상도 MSE·ZNCC를 구현하고 기존 MSE·MS-SSIM과 같은 후보에서 비교했다. 관련 요구는 F6·F9·F12·N1–N3·N6이며 현재 실행 방법과 정의는 README·TECH에 둔다.

전곡을 다시 검색하거나 기본 설정을 변경하지 않았다. `p6-full`이 저장한 100만 장소·400만 회전 view의 MSE Top-20을 재사용한다. 각 원본 프레임의 20개 view를 모두 평가하고, 원래 첫 다섯 **서로 다른 장소**로 제한했던 MS-SSIM의 선택도 계산해 후보 범위 변경의 영향을 기록한다. 이는 새 지표의 100만 전수 검색이 아니다.

## 구현과 계산 조건

`production/metrics.py`, `fsim.py`, `comparison.py`와 `compare-metrics` CLI를 추가했다. 기존 `produce`의 다섯 장소 선택 계약과 완성된 전곡 파일은 유지한다.

FSIM은 [저자 FeatureSIM.m](https://cslinzhang.github.io/home/FSIM/Files/FeatureSIM.m)의 grayscale 경로와 전용 phase congruency를 NumPy/SciPy로 이식했다. 일반 `phasecong2`의 기본 설정과 다르게 4스케일·4방향·최소 파장 6·배수 2·각도 계수 1.2이며, Scharr 영 채움과 T1=.85·T2=160을 따른다. Kovesi 필터의 잡음 에너지 합은 `2*sum((sum_s h_s)^2)`로 묶어 사전 계산했다. 자동 추가 다운샘플이 필요 없는 canonical 크기다. 포트의 저작권·연구/교육 목적 이용 조건을 THIRD_PARTY_NOTICES에 남겼다. MATLAB 실행과의 수치 대조는 하지 않았다.

다중 해상도 MSE는 폭 64·32·16, 높이 48·24·12로 BOX 축소한 세 MSE를 같은 가중치로 합친다. ZNCC는 full canonical 명암의 평균 제거·정규화 내적으로 계산하며 음의 상관을 양의 상관으로 바꾸지 않는다. MS-SSIM은 이전 구현을 그대로 재사용한다. MSE 기준선은 기존 16×12 특징의 정확 검색 순위를 유지한다.

FSIM phase weight 합이 0이면 `1-full_resolution_MSE`, ZNCC 분산이 0이면 -1로 처리한다. 타깃이 단색이면 ZNCC 후보가 모두 동률이므로 MSE 순위를 유지한다. 모든 지표의 동률은 MSE 순위·view ID 순이다. 선택을 다양하게 만들기 위한 임의 점수·순위 변경은 없다.

실행은 uv·8 CPU 프로세스, BLAS/OpenMP 각 1스레드다. 프로세스별 bounded 특징 캐시와 20프레임 단위 점수 체크포인트를 사용한다. 지표 계산 30.832초, 사진 준비·Parquet·인코딩 포함 총 101.752초였다. 개별 알고리즘별 시간을 따로 측정한 값은 아니다.

## 관측한 선택

| 지표 | MSE 첫 후보와 다른 프레임 / 300 | 선택 장소 수 | 선택 사진의 평균 검색 MSE |
| --- | ---: | ---: | ---: |
| MSE | 0 | 76 | .046639 |
| MS-SSIM, Top-20 | 237 | 80 | .052331 |
| FSIM | 260 | 60 | .054344 |
| 다중 해상도 MSE | 73 | 74 | .046958 |
| ZNCC | 227 | 83 | .050700 |

Top-20 MS-SSIM은 기존 다섯 장소로 제한한 MS-SSIM과 140프레임에서 다른 view를 골랐다. 기존보다 달라진 결과에는 지표 변경과 후보 범위 확대를 구분해야 한다. 점수 단위가 서로 다르므로 지표 사이의 숫자를 직접 비교하지 않으며, 선택 변경 수·장소 수는 시각 품질 개선량이 아니다.

## 산출물과 필요한 확인

- `comparison.mp4`: 위쪽 원본·MSE·MS-SSIM, 아래쪽 FSIM·Multi-MSE·ZNCC. 1920×1080 H.264/yuv420p, 300프레임, 30000/1001fps, 10.010초, 무음. 프레임 건너뛰기·복제·보간 없음.
- `evaluations.parquet`: 모든 300×20 후보의 점수·원래 순위·실제 출처·좌표·추출 창·회전과 source PTS.
- `selected.parquet`: 300×5 방법별 최종 선택과 점수.
- `scores/`: 재개 가능한 모든 원본 프레임의 점수·선택·다섯 장소 MS-SSIM 선택.
- `manifest.json`: 입력 식별자·계산 버전·설정·실행 비용·선택 분포·캐시 사용량.
- `preview.png`: 구간 중간 실제 프레임의 2×3 화면.

변경된 지표와 기존 MS-SSIM의 오프라인 테스트 5개가 3.95초에 통과했다. FSIM 정체성·대칭·구조 차이·단색, ZNCC 밝기/대비·반전·분산 0, 다중 해상도 MSE와 점수 방향·동률을 확인했다. 실제 비교 영상은 ffprobe로 프레임 수·fps·크기·시작·길이를 한 번 확인하고 대표 화면을 열어 패널·순위·점수·카운터가 읽히는지 확인했다. 전체 재생의 주관적 우열이나 새 지표의 전곡 채택은 아직 판정하지 않았다.

실제 평가 6,000행·선택 1,500행과 300개 원본 slot의 대응을 확인했다. MSE 선택은 `p6-full`의 같은 300프레임과 모두 같았고, 같은 점수에서 첫 다섯 장소로 제한한 MS-SSIM 선택은 `p6-refined`의 같은 300프레임과 모두 같았다. 이 대조는 기존 방법 재현과 후보 범위 변경을 구분하기 위한 확인이며 재검색·재다운로드는 하지 않았다.
