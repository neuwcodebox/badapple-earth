# P5 — 100만 후보 확대와 수집 병렬화

관련 요구: F2–F7, F10, F11, N2, N3. 기본 검색은 MSE이며 기존 10만 결과와 같은 38–48초 목표 60개를 비교한다.

## 구성과 비용

기존 `data/index/p4-100k`의 10만 장소를 보존하고 `config/collect-million.json`으로 90만 장소를 추가한다. 기존 60개 중심 지역과 새 60개 중심 지역 주변의 비중첩 1도 AOI를 다섯 개씩 사용한다. 기존 72개 AOI와의 면적 중첩도 피한다. 여섯 지형군에 각 100개 AOI이며 지형군은 계획 분류다. 이 분류를 실제 토지피복 검증이나 모든 후보가 서로 다른 형태라는 근거로 사용하지 않는다.

폭 256/512/1024/2048px 시작 가중치는 15:30:40:15다. 완전 유효·로컬 구름 2% 이하 정책은 유지하고 통과 후보 부족분만 기존 규칙으로 재배분한다. 2048px 창의 높이는 입력 종횡비에서 유도한다.

`collect-parallel`은 지형군별 AOI를 결정적으로 네 작업에 분할하고 작업당 225,000개를 수집한다. 독립 writer/SQLite/로그를 사용해 기존 체크포인트·원자적 shard 공개를 재사용한다. 전체 프로세스는 자식 종료를 기다리며 주기적인 전체 인덱스 스캔을 하지 않는다. 각 작업은 수집 중 블록 경계에서 자원 한도를 확인한다.

시작 시 D 드라이브 여유는 약 271GiB였다. 각 작업의 RAM 예산은 3GiB, 디스크 예산은 55GiB이며 공유 드라이브 여유 하한은 20GiB다. 신규 RGB 90만 행은 약 126GiB이며 원격 블록·특징·메타데이터도 저장한다. 무료 공개 C1 HTTPS만 사용하고 유료 접근·클라우드 실행은 추가하지 않는다.

## 구현과 필요한 검증

수집 중 만든 RGB를 `rgb.npy`에 무손실로 저장하고 원본 후보와 회전 view에서 같은 행을 참조한다. RGB·특징·좌표를 함께 공개해 후속 출력에서 정상 수신 자료를 다시 내려받지 않는다. 기존 캐시·인덱스·형태 실험은 유지한다.

초기 약 2.8만의 저장량을 바탕으로 남겨 둔 원본 블록까지 유지하면 전체 디스크 예산을 넘을 가능성을 확인했다. 전체 RGB를 저장하는 경우에는 단일 writer가 AOI 처리를 마친 뒤 원본 블록 캐시를 비우도록 보완했다. 채택 RGB와 출처는 유지하며 quota 증가로 새 창이 필요할 때만 원본을 다시 읽는다. 38,435개가 공개된 시점에 작업 프로세스를 종료하고 체크포인트에서 재개해 이 정책을 적용했다. RGB 계약 테스트에 원본 블록 퇴출 후 무네트워크 사진 재생도 포함해 통과했다.

변경 영향에 해당하는 수집·확대·병렬 분할 및 RGB 캐시 계약 테스트 11개와 서로 다른 스키마의 이전/신규 인덱스를 결합하는 검색 계약 테스트 1개가 통과했다. 검색 Parquet는 이전 후보가 첫 행이어도 새 후보의 RGB 참조를 보존한다. 임시 폴더에 쓰지 못한 첫 테스트 실행은 프로젝트 내부 `--basetemp`로 해결했다. 네트워크 재다운로드 검증은 수행하지 않았다. 최초 자식 실행에서 패키지 모듈 진입점이 없어 즉시 종료한 문제를 `__main__.py`로 해결한 후 같은 명령으로 재시작했다.

```bash
uv run badapple-earth collect-parallel --config config/collect-million.json --output data/index/p5-additional-900k --limit 900000 --workers 4
```

실행 상태·작업별 로그·설정은 해당 폴더의 `collection.json`, `part-01.log`–`part-04.log`, `part-01.json`–`part-04.json`에 남는다. 같은 명령은 각 인덱스를 재개한다.

이번 로컬 실행은 `.local/finish_million.py`를 함께 실행해 수집 완료 후 결합·MSE 검색·사진 출력·렌더·10만 기준선 비교를 이어가도록 했다. 수집 상태 확인 간격은 10분이며 중간 실패나 고유 수 미달이면 후속 처리를 멈춘다. 처리 상태는 `.local/million-pipeline.json`에 남긴다.
