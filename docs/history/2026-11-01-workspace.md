## 구체화와 정정

### 실제 요청을 반영한 범위

사용자가 가진 MP4를 로컬 입력으로 받는다. 실행 코드·테스트 파일·패키지 의존성 파일·더미 데이터·빈 결과 영상은 생성하지 않았다. 문서의 예정 구조는 이후 구현 시 만들 대상이지 ZIP에 이미 구현되어 있다는 뜻이 아니다.

기본 결과는 한 장소의 컬러 사진이다. 초기에 제안되었던 흑백 우선·모자이크 완성형·연속성 강제 같은 방향으로 되돌리지 않았다. 1만 후보의 실제 검색·재생 평가를 10만 이상 수집보다 앞에 배치했다.

### 실제 소스 접근과 비용

2026-11-01 공식 STAC 컬렉션과 데이터 제공 안내를 재확인했다. Sentinel-2 C1의 `visual`/`scl`, NAIP의 `image` 정의를 확인했으나 실제 COG 읽기는 수행하지 않았다.

NAIP AWS 버킷은 Requester Pays로 안내되어 있어 무료 공개 이미지라는 표현만으로 무료 다운로드를 가정하지 않도록 정정했다. Microsoft Planetary Computer 경로는 조건부 대안이며 실제 읽기·서비스 조건 확인이 필요하다. NAIP에 Sentinel의 최근 날짜·구름 필터를 그대로 적용하지 않는다. 근거는 [TECH의 R1–R5](../TECH.md#공식-참고-자료)에 있다.

### 구현 오류를 막는 구체화

- 90/270도 회전은 비정사각형 후보의 축만 바꿔 flatten하는 방식이 아니라, 실제 창·회전·크롭·화각을 동일하게 처리한다.
- 창 중심은 affine의 픽셀 경계 좌표에서 계산하여 `xy()`의 기본 0.5px 오프셋을 중복 적용하지 않는다. 과거 P0 샘플은 그대로 실행할 완성 코드가 아니다.
- MSE는 uint8 overflow를 피하도록 float32에서 계산한다. 한꺼번에 모든 타깃×후보×차원을 방송 연산하지 않는다.
- 95% 유효 후보의 보관과 최종 출력의 결측 없는 사진을 구분한다. NoData를 검은 형태로 이용하지 않는다.
- 전역 가변 행 번호 대신 shard와 내부 행 매핑, staging→commit 복구 계약을 구체화했다.
- 생성된 특징만으로 실제 사진성을 주장하지 않도록 선택 사진·변환·출처를 연결하고 원격 변동·재추출 실패를 처리한다.

이 정정은 프로젝트 콘셉트 변경이 아니라 실제 구현에서 발생할 수 있는 모호함과 잘못된 가정을 해소하기 위한 것이다.

## 수행하지 않은 일

애플리케이션 코드 작성, 의존성 설치, MP4 분석, STAC item의 실제 raster 다운로드, 후보 수집, 수집기 속도·RAM 측정, 매칭 성능·시각 품질 평가, 영상 렌더링, 원본/음원 권리 확인, GitHub 저장소 수정/커밋/푸시는 하지 않았다. 공식 메타데이터 열람과 문서 검증을 제품 통합 테스트 통과로 표시하지 않는다.
