# 밝기 연속 선택과 큰 사진 중심의 흑백 전곡

관련 요구·단계는 F5–F9, F11–F14, N1–N7, P6다. 사용자는 흑백이 더 낫다고 평가했고, 최종 색감 연속성도 흑백 기준으로 바꾸도록 요청했다. 이어 출처를 좌표·촬영 연도와 같은 줄에 합치고 아래 여백·최종 연결선의 가로 공간을 줄여 사진을 키우며 알고리즘명 표기를 없애도록 했다. 기존 컬러와 단순 흑백 영상은 보존한다.

## 선택과 출력

- 완료한 `data/runs/p6-silhouette-color-full/choices.parquet`의 형태 허용폭 .02·최대 24개 후보를 재사용한다. 실제 대상은 **5,576개 고유 view·13,028개 프레임/view 쌍**이다. 2,880만 view 검색과 약 655만 쌍의 형태 평가는 다시 하지 않는다.
- 새 `luminance_descriptor`는 64×48 명암의 원본 흰/검정 영역별 평균과 16 bin 선형 보간 histogram을 구한다. 영역 면적과 무관하게 각 영역에 동일 비중을 주며 평균 제곱 거리 .2·제곱근 histogram 제곱 거리 .8로 구성한다. 색상은 사용하지 않는다.
- 전곡 경로는 기존 형태 점수 손실과 인접 명암 거리 .2배의 합을 동적 계획법으로 최소화한다. 기존 사진 유지 시간이나 같은 사진 보너스는 추가하지 않았다. 단색·시인성 통과 후보 없음의 기존 fallback은 그대로다.
- `production/silhouette/monochrome.py`와 `config/silhouette-luminance.json`이 실행 경로다. source production ID와 descriptor·배치 버전·설정으로 파생 run을 구분한다. 새로 필요한 사진 상세만 준비하고 이전 native·썸네일을 재사용한다. 사진 선택·프레임 PTS·출처를 저장하며 오디오는 기존 로컬 입력에서 해당 콘텐츠 구간을 복사한다.

## 화면 배치

- 큰 사진을 `(728,72,1152,862)`에서 **`(552,20,1344,1005)`**로 키웠다. 면적은 약 36% 늘었다.
- 후보 사진은 x310·폭206, 큰 사진과의 간격은 **36px**다. 최종 연결 곡선을 이 간격 안에 넣었다. 원본·후보를 잇는 왼쪽 분기도 배치 상수에서 계산한다.
- 사진 아래 y1042의 **한 줄에 좌표·촬영일·전체 출처**를 모았다. 실제 문자열 폭에 맞춰 폰트를 줄여 출처를 생략하지 않는다. 알고리즘명 표기는 제거하고 후보 번호·참고 점수와 시간·프레임 카운터만 유지한다.
- `monochrome` 설정으로 설명 화면과 사진 전용 출력 모두 흑백으로 만든다. 명암 대비 조정·이진화·실루엣 합성은 하지 않는다. 배치 버전은 `compact-hero-inline-provenance-v5`다.

## 실행·변경 범위 검증

새 명암 descriptor의 오프라인 테스트 **3개 통과**: 표시되는 명암이 같으면 색이 달라도 동일, 타깃 소수 영역 면적 변화와 무관한 영역별 descriptor, histogram bin 경계의 작은 밝기 변화와 큰 변화 구분이다. 합성 사진은 테스트 전용이다. 기존 출처·좌표·다운로드·전체 시간축 검수를 반복하지 않았다.

새 배치는 실제 기존 프레임 41초와 전체 provenance 문자열이 가장 긴 장면의 PNG를 확인했다. 원본/후보/큰 사진과 하단 한 줄이 겹치지 않고 전체 출처가 들어간다. 미리보기는 `.local/compact-representative.png`와 `compact-longest-credit.png`다. 배치 확인용 미리보기의 사진 선택은 기존 결과이며 새 선택의 전체 재생 평가로 보고하지 않는다.

20:13:40 KST에 새 run을 시작해 74개 명암 특징 배치를 완료하고 **20:13:54 KST에 사진 준비 단계**로 넘어갔다. 최종 선택은 기존 색감 경로와 **934프레임**이 다르다. 자체 인접 명암 거리 평균은 **.186212→.155510**, 약 16.5% 감소했다. 이는 선택 목적에 사용한 지표이며 인지 품질 개선을 보장하지 않는다. 평균 형태 점수는 .550594다. 출력 경로는 `data/runs/p6-silhouette-luminance-full/`, 로그는 `.local/silhouette-luminance-full.log`다. 전체 영상은 아직 생성 중이며 초기 완료 예상은 **20:25–20:30 KST**다.
