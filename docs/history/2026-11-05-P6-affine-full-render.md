## 완료 계산과 출력 상태

- 실제 1,200,000개 장소·28,800,000 view의 전곡 검색을 완료했다. 원본 6,955프레임·고유 6,423질의 중 기존 affine 300질의를 재사용했다. 기존 직각 Top-20도 재사용했다.
- 검색 ID는 `f979319abca9b94658a6de53751b2e77e931542ac475dbfeab0a2131542bb659`, view-space ID는 `c4c25397e04db00fe08b75fedc829eb5c91e59457cf5743f54193b206d45f186`다. 평균 Best fine MSE는 약 0.06038352이며 재생 품질 개선을 뜻하지 않는다.
- MS-SSIM 139,100쌍 중 27,228쌍을 재사용하고 111,872쌍을 새로 계산했다. 81개 RGB 평가 그룹이 모두 저장됐다.
- 사진 후보를 표시하는 단계에서 고유 tile ID가 다섯 미만인 query가 발견돼 기존 강제 조건이 `ValueError`를 발생시켰다. 한 장소가 24 view를 갖게 되면서 Top-20이 다섯 장소 미만일 수 있다. 검색·점수는 정상 완료됐고 원본 프레임·선택 점수는 변경하지 않았다.
- 실제 후보군의 승자를 유지한 채 최대 다섯 고유 장소만 표시하도록 수정했다. 실제 후보가 적으면 채우기용 사진·순위·연결선을 만들지 않는다. 레이아웃은 후보 수·선택 위치별 연결선을 캐시하며 render layout 버전을 v4로 올렸다. 아직 이 run의 인코딩 segment는 없었다.
- `tests/test_sparse_candidate_display.py`, `tests/test_fine_production.py`, 기존 segment 생성·재개 계약의 영향 범위 **15개 통과**. 고유 장소 1–4개/순위 또는 재평가 표시, 실제 승자·방향 유지, count=1, 단일 후보 화면의 빈 연결선 부재, 실제 FFmpeg 3프레임/PTS·재개를 확인했다.

19:20경 `.local/produce_aerial120_views30.py`를 같은 설정·출력 run으로 재실행했다. 로그는 `.local/produce-aerial120-views30-display-recovery.log`다. 완료한 검색 manifest와 모든 RGB 점수 그룹을 그대로 읽고 사진 출력·선택 detail·렌더·원본 오디오 결합으로 이어간다. 19:21에는 썸네일 1,518개가 게시됐으며 사진 준비 단계였다. 당시 예상은 19:45–20:00 KST로 안내했다. 이는 측정 중인 추정이며 **최종 새 전곡·입력 계약·전체 재생 품질은 아직 완료/검증으로 표시하지 않는다.**
