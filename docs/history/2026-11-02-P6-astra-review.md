# P6 — Astra의 블라인드 후보 시각 검토

## 요청과 방식

사용자가 후보 사진을 직접 검토하되 이미지 비교는 Astra 모델에게 맡기도록 요청했다. `gpt-6-astra`(high reasoning)의 별도 검토 작업에 원본과 실제 원색 후보를 보여줬다. 모델에는 기존 선택·점수·검색 순위를 공개하지 않았고, 사진의 시각 판단을 확정한 뒤에만 선택 정보를 공개했다. 제작 코드와 기본 설정은 변경하지 않았다.

전곡의 고정 시점 15·45·75·105·135·165·195·225초와, 기존 비교 구간의 진단 시점 38.5·40·41·47초를 사용했다. 실제 가까운 source slot과 원래 PTS는 산출물에 기록했다. 점수의 높고 낮음으로 프레임을 선별하지 않았다. 각 시점의 32×24 MSE Top-20을 섞어 P01–P20으로 표시했다. 후보는 canonical 원색 RGB 256×191이며, 원본도 같은 크기와 확대본으로 함께 제시했다. 이 240개 제시는 고유 사진 238개에 해당한다.

두 번째 단계에서는 진단용 네 시점마다 기존의 더 넓은 검색 풀에서 새로운 장소 32개를 추가했다. 풀은 MSE 16/32 각 Top-512와 ZNCC/GC 각 Top-512의 합집합이다. 원래 Top-20의 tile과 다른 사진 중 기존 MS-SSIM 상위 16개(장소 중복 제거), 고정 seed로 다른 scene을 우선한 16개를 골랐다. 원래 MSE/MS-SSIM 선택 두 장도 가림 앵커로 섞어 Q01–Q34로 제시했다. 추가 128장과 앵커 8개를 판단한 뒤에도 최초 평가는 소급 변경하지 않았다. 512개 전체나 100만 데이터 전체를 눈으로 본 것은 아니다.

사진 준비는 기존 PNG·RGB만 사용했다. 새 검색·점수 재계산·원격 읽기·영상 재제작·프로그램 동작 재확인은 하지 않았다. 이미지 비교는 Astra가 담당했으며 주 에이전트는 시트 생성, 선택 정보 연결과 보고서 작성을 맡았다.

## 판정 기준

| 등급 | Astra가 사용한 의미 |
| --- | --- |
| A | 별도 설명 없이 핵심 실루엣이 비교적 읽힘 |
| B | 원본을 옆에 두면 핵심 윤곽의 일부가 읽힘. 독립적인 인물·동작 인지를 뜻하지 않음 |
| C | 명암 면적·위치·방향의 부분 유사만 있고 형태 인지는 어려움 |
| D | 주요 형태 배치나 극성도 불일치 |

단순 원형·확대 경계·작은 물체·크레딧을 복합 인물 장면과 분리했다. 단일 모델의 고정 표본 평가이며 사람의 인지 실험이나 전곡 재생 품질 결과로 해석하지 않는다.

240개 후보의 등급은 A 0개·B 23개·C 191개·D 26개였다. 원본이 복합 형상인 여덟 시점만 보면 A 0개·B 12개·C 135개·D 13개다. B도 원본을 보고 일부 대응점을 찾는 약한 인지이며 완전한 포즈를 재현한 사진은 없었다.

**선택 단계의 누락:** C01·C04·C06·C11·C12의 다섯 시점에는 B 후보가 있었지만 두 방식 모두 C를 골랐다. 이 차이는 데이터나 후보 수를 늘리지 않고도 개선할 여지가 있다. MS-SSIM도 C05에서는 MSE가 고른 B를 버리고 C를 골랐다.

MS-SSIM이 B를 고른 사례는 4개, MSE는 2개다. 등급만 비교하면 MS-SSIM 우위 4개·MSE 우위 1개·동급 7개지만, MS의 우위에는 단순 경계와 크레딧 D→C가 포함된다. 복합 형상 여덟 개로 제한하면 MS 우위 2개·MSE 우위 1개·동급 5개다. 이를 일반적인 알고리즘 우열로 확대하지 않는다.

## 해석과 다음 판단

1. **확인된 문제는 선택 지표의 누락이다.** 같은 후보 20장 안에서 더 나은 부분 대응을 놓치는 사례가 실제로 있었다. 따라서 데이터셋만의 문제라고 할 수 없다.
2. **관찰한 후보군의 절대 품질도 낮다.** 최선을 골라도 머리·팔·치마·연결부의 일부만 대응하며 복합 실루엣 전체를 읽기는 어려웠다. 점수 상승과 형태 인지의 차이를 구분해야 한다.
3. **데이터 부족과 검색 누락은 아직 분리되지 않았다.** 좋은 사진이 전체 데이터에 없는지, 초기 표현/검색이 꺼내지 못하는지, 이번 추가 표본에서 빠졌는지는 이 검토로 결정할 수 없다.
4. 후보 수를 무조건 늘리거나 새 지표를 바로 채택하지 않는다. 현재 후보를 고정한 상태에서 이번 시각 최선과 자동 선택이 달라진 이유를 먼저 다루고, 별도 시점에서 효과를 비교한다. 자료 확대는 형태·지형·촬영 스케일의 다양성 관점에서 계속 검토하되 이번 표본으로 확대의 효용이나 무효를 단정하지 않는다.
